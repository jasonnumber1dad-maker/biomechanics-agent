# Apex Fastpitch Biomechanics Agent

A softball pitching and hitting biomechanics analyzer built with Streamlit.

## Features

- Upload softball pitching videos
- Upload softball hitting videos
- Video playback inside the application
- Biomechanics dashboard
- Foundation for AI-powered movement analysis

## Current Status

This is an early demonstration version.

### Current Functionality

- Video upload
- Video playback
- Example metrics display

### Future Functionality

- MediaPipe pose estimation
- Joint angle measurements
- Kinematic sequencing analysis
- Pitching mechanics scoring
- Swing efficiency scoring
- AI coaching recommendations

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

- Python
- Streamlit
- MediaPipe
